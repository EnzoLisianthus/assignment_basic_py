# 대동제 및 해커톤 로그 정규표현식 추출

파이썬 기초 및 실습 통합과제입니다. 정규표현식을 이용해 텍스트 로그에서 필요한 정보만 추출하고, 부스별 매출액을 합산합니다.

## 사용한 내용

- `with open()`으로 UTF-8 텍스트 파일 읽기
- `re.findall()`을 이용한 패턴 검색
- 문자열 처리, `for` 반복문, `int()` 변환으로 매출 합산

## 실행 방법

1. 파이썬 3이 설치된 환경에서 `main.py`와 과제에서 제공한 원본 로그 파일을 같은 폴더에 넣습니다.
2. 해당 폴더에서 다음 명령어를 실행합니다.

```bash
python main.py
```

별도의 라이브러리 설치는 필요하지 않습니다.

입력 파일 이름: `07-02. 전주대 대동제 및 해커톤 통합운영 데이터 로그.txt`

> GitHub에 원본 로그를 게시하지 않는 경우, 수업에서 제공된 파일을 별도로 내려받아 같은 폴더에 넣어 실행하면 됩니다.

## 구현 내용

| 항목 | 추출 조건 | 제공된 로그의 결과 |
|---|---|---:|
| 이메일 | `@` 뒤에 정상적인 도메인과 최상위 도메인이 있는 주소 | 5개 |
| 휴대폰 | `010`으로 시작, 4자리-4자리, 구분자 `-`, `.`, 공백 | 4개 |
| 학번·학과 | `[202xxxxxx / 학과]` 형태, 9자리 학번 | 3개 튜플 |
| GitHub | `github.com` 저장소 주소, `http` 및 `https` 허용 | 3개 |
| 쿠폰 | `FEST-2026-XXXX` 형식 | 3개 |
| 매출 | 각 부스의 `매출:` 바로 뒤 금액만 선택 | 4개 |

### 제외 조건 확인

- `hyunwoo@.ac.kr`: 도메인이 잘못되어 이메일에서 제외
- `063-3290-1114`, `010-123-4567`: 휴대폰 형식에 맞지 않아 제외
- `[20261122 / 데이터공학과]`, `[999900000 / 전북대학교]`: 학번 조건에 맞지 않아 제외
- `https://gitlab.com/yujin-dev/demo-project`: GitHub가 아니므로 제외
- `FEST-2025-OLD9`: 2026년도 쿠폰이 아니므로 제외
- 카드·현금 세부 내역 및 쿠폰 액수: `매출:` 뒤의 금액이 아니므로 제외
