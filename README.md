# 대동제·해커톤 로그 정보 추출

파이썬 기초 및 실습 통합과제입니다. 제공된 로그에서 이메일, 휴대폰 번호, 학번과 학과, GitHub 주소, 2026년 쿠폰 코드, 부스별 매출을 추출하는 프로그램을 작성했습니다.

## 구현 내용

with open()으로 텍스트 파일을 읽고 re.findall()과 정규표현식의 문자 범위, 반복 횟수, 그룹을 사용했습니다. 이메일과 휴대폰 번호는 형식을 검사하고, 학번과 학과는 그룹으로 나누어 튜플로 출력했습니다. GitHub 주소와 2026년 쿠폰은 지정된 문자열과 연도를 기준으로 추출했습니다.

매출은 각 부스의 '매출:' 뒤에 있는 금액만 찾고, replace()로 쉼표를 제거한 다음 int()로 변환했습니다. for문을 이용해 부스별 매출을 출력하고 전체 금액을 합산했습니다.

## 실행 및 결과

main.py와 원본 TXT 파일을 같은 폴더에 두고 python main.py를 실행합니다. 별도의 라이브러리 설치는 필요하지 않습니다.

이메일 5개, 휴대폰 번호 4개, 학번·학과 3쌍, GitHub 주소 3개, 쿠폰 3개, 부스 매출 4건을 추출했으며 총 매출은 6,290,500원입니다.
