# 대동제·해커톤 로그 정보 추출

파이썬 기초 및 실습에서 배운 정규표현식을 이용해 학교 행사 운영 로그에서 필요한 정보를 추출하는 프로그램입니다.

## 구현 내용

with open()으로 텍스트 파일을 읽고, re.findall()을 사용해 이메일, 휴대폰 번호, 학번과 학과, GitHub 주소, 쿠폰 코드를 추출했습니다. 문자 범위와 반복 횟수를 지정해 형식이 맞지 않는 데이터는 제외하도록 했습니다.

학번과 학과는 그룹을 이용해 튜플로 구분했습니다. 부스 매출은 '매출:' 뒤에 나오는 금액만 추출한 뒤 쉼표를 제거하고 int()로 변환했습니다. 이후 for문으로 전체 매출을 합산했습니다.

이번 과제를 통해 정규표현식은 단순히 문자열을 찾는 것뿐 아니라, 여러 정보가 섞인 데이터에서 필요한 값만 구별하는 데 사용할 수 있다는 점을 확인했습니다.

## 실행 방법 및 결과

main.py와 제공된 TXT 파일을 같은 폴더에 두고 python main.py를 실행합니다. 별도의 라이브러리 설치는 필요하지 않습니다.

이메일 5개, 휴대폰 번호 4개, 학번·학과 3쌍, GitHub 주소 3개, 쿠폰 3개, 부스 매출 4건을 추출했고, 전체 매출은 6,290,500원입니다.
